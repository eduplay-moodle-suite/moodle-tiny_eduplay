Configuração
============

O plugin não tem configurações próprias.

* O botão **EduPlay** é adicionado, por padrão, à seção *content* da barra de ferramentas do TinyMCE e ao menu *Inserir*.
* Para mudar a posição, acesse *Administração do site* > *Plugins* > *Editores de texto* > *Editor TinyMCE* > *Configurações gerais* e edite a barra de ferramentas; o nome do botão é ``tiny_eduplay/tiny_eduplay``.
* Verifique se o media player **EduPlay** está habilitado (*Gerenciar media players*) e se o filtro **Plugins de multimídia** está ativo; caso contrário, o link inserido permanece como link normal.

Privacidade
-----------

O plugin não armazena dados pessoais.
