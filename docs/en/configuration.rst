Configuration
=============

The plugin has no settings of its own.

* The **EduPlay** button is added to the *content* section of the TinyMCE toolbar and to the *Insert* menu by default.
* To change the position, go to *Site administration* > *Plugins* > *Text editors* > *TinyMCE editor* > *General settings* and edit the toolbar; the button name is ``tiny_eduplay/tiny_eduplay``.
* Make sure the **EduPlay** media player is enabled (*Manage media players*) and that the **Multimedia plugins** filter is on, otherwise the inserted link stays a normal link.

Privacy
-------

The plugin stores no personal data.
